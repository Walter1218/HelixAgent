# ComfyUI 调研及可借鉴点

## 一、ComfyUI 是什么

ComfyUI 是一个开源的**节点式生成式 AI 界面和推理引擎**，核心用于 Stable Diffusion 图像生成，同时支持视频、3D、音频等多种模态。

- 官网：https://www.comfy.org/
- 文档：https://docs.comfy.org/
- GitHub：https://github.com/Comfy-Org/ComfyUI

## 二、核心特点

| 特点 | 说明 |
|---|---|
| 节点式工作流 | 拖拽连接节点构建生成管线，工作流可保存为 JSON |
| 高可控性 | 可精确控制每个模型、参数、采样步骤 |
| DAG 执行 | 按依赖图调度，无依赖节点可并行执行 |
| 增量重算 | 只重新执行工作流中变化的部分 |
| 显存优化 | 智能卸载，最低 1GB 显存也能运行 |
| 模型解耦 | 支持 SD、SDXL、Flux、Hunyuan、Wan 等多种模型 |
| 插件生态 | 1000+ 自定义节点，可扩展性强 |
| 跨平台 | Windows / Linux / macOS，支持桌面版和云端 |

## 三、视频生成支持

ComfyUI 原生支持的视频模型：

- Stable Video Diffusion
- Mochi
- LTX-Video
- Hunyuan Video / Hunyuan Video 1.5
- Wan 2.1 / Wan 2.2

可通过节点组合实现文生视频、图生视频、视频编辑等流程。

## 四、对 CreatorHelix 的借鉴

### 1. 工作流抽象：从节点到任务步骤

- 把视频生成拆成原子步骤：脚本 → 分镜 → 关键帧 → 视频片段 → 配音 → 剪辑
- 用 DAG 描述依赖关系
- 人工修改某一步后，只重跑下游依赖步骤

### 2. 人机协作模式

| ComfyUI | CreatorHelix |
|---|---|
| 用户从零连节点 | Agent 预生成完整工作流 |
| 用户调每个参数 | 用户只在关键决策点介入 |
| 工作流保存复用 | 生成项目剧本模板 |

### 3. 模型与工具解耦

- 视频模型可插拔替换
- 每个工具（TTS、字幕、剪辑、BGM）都抽象为节点
- 统一数据格式在节点间传递

### 4. 缓存与执行优化

- 智能显存/内存卸载
- 多任务队列
- 部分重算：用户改一句旁白，只重跑 TTS 和最终合成

### 5. 可复现性

- 每次生成保存完整参数快照
- 输出文件嵌入元数据
- 工作流变更可 diff

### 6. 生态扩展机制

- 插件市场
- Agent 工具注册协议
- 社区工作流/模板共享

## 五、不建议照搬的地方

- **不要暴露完整节点图给普通用户**：界面应是剧本 + 时间轴 + 预览
- **不要让用户手动连节点**：那是专业用户场景
- **不要完全本地离线**：云端推理 + 本地预览更适合视频生成
