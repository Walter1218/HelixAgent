# AnimeHelix AGENTS.md

## 项目概述

AnimeHelix是一个基于Blender + AI视频生成的创意视频制作项目，专注于高质量视频内容创作。

## 核心目标

1. **电商产品视频**：产品展示、品牌宣传、广告素材
2. **剧情类短剧**：人物故事、情感叙事、微电影
3. **科幻类视频**：未来场景、特效展示、概念动画
4. **其他类型**：MV、教程、纪录片等

## 工作流程规范

### 标准制作流程

```
1. 需求分析 → 2. 脚本/分镜 → 3. Blender预制作 → 4. AI增强 → 5. 后期处理 → 6. 输出交付
```

### 阶段职责

| 阶段 | 工具 | 输出物 |
|------|------|--------|
| 需求分析 | 文档 | 需求文档、参考图 |
| 脚本/分镜 | Blender/GIMP | 分镜草图、动作脚本 |
| Blender预制作 | Blender | 3D场景、动画、渲染帧 |
| AI增强 | Seedance/可灵 | 风格化视频、特效 |
| 后期处理 | FFmpeg/DaVinci | 调色、剪辑、配乐 |
| 输出交付 | 编码器 | 最终视频文件 |

## Blender操作规范

### 场景搭建原则

1. **简洁优先**：保持场景简单，复杂度交给AI增强
2. **模块化**：将场景分解为可复用的组件
3. **命名规范**：所有对象使用有意义的名称

```python
# 好的命名
product.name = 'RedBox_Main'
camera.name = 'Camera_ProductView'
light.name = 'KeyLight_Warm'

# 不好的命名
product.name = 'Cube'
camera.name = 'Camera'
light.name = 'Light'
```

### 摄像机设置

**必须使用Track To约束**确保摄像机对准目标：

```python
constraint = camera.constraints.new(type='TRACK_TO')
constraint.target = target_object
constraint.track_axis = 'TRACK_NEGATIVE_Z'
constraint.up_axis = 'UP_Y'
```

### 灯光设置

使用三点布光系统：
- **主灯（Key Light）**：主要照明，能量1000-2000
- **补光（Fill Light）**：柔和阴影，能量500-800
- **轮廓光（Rim Light）**：突出轮廓，能量300-500

### 渲染设置

| 用途 | 引擎 | 分辨率 | 帧率 |
|------|------|--------|------|
| 快速预览 | EEVEE | 256×256 | 24fps |
| 标准输出 | EEVEE | 512×512 | 30fps |
| 高质量输出 | Cycles | 1024×1024 | 30fps |

## AI视频生成规范

### Prompt工程

**结构**：风格描述 + 主体描述 + 动作描述 + 环境描述 + 镜头语言 + 质量修饰词

**示例**：
```
电影级画质，一个红色产品盒子在黑色旋转台上360度旋转，
柔和的轮廓光勾勒出产品边缘，背景是渐变色摄影棚，
镜头缓慢环绕，浅景深效果，8K分辨率
```

### 模型选择

| 场景 | 推荐模型 | 原因 |
|------|----------|------|
| 产品展示 | 可灵Pro | 画面稳定，细节清晰 |
| 剧情短剧 | Seedance 2.0 | 多模态支持，音视频同步 |
| 科幻特效 | Runway Gen-3 | 风格化能力强 |
| 快速验证 | 可灵标准 | 成本低，速度快 |

## 类型视频制作指南

### 1. 电商产品视频

**目标**：展示产品外观、功能、使用场景

**Blender设置**：
- 产品模型：简洁几何体或导入真实模型
- 材质：金属、玻璃、塑料等真实质感
- 动画：旋转、拆解、使用演示
- 灯光：三点布光，突出产品质感

**AI增强重点**：
- 光影效果：轮廓光、反射、折射
- 背景：渐变色、摄影棚、使用场景
- 镜头：环绕、推拉、特写

**输出规格**：
- 分辨率：1080P或4K
- 时长：5-15秒
- 格式：MP4 (H.264)

### 2. 剧情类短剧

**目标**：讲述故事、传递情感、塑造角色

**Blender设置**：
- 角色：简化人形或卡通角色
- 场景：室内、室外、特定环境
- 动作：走路、对话、交互
- 镜头：正反打、跟随、全景

**AI增强重点**：
- 角色一致性：保持角色外观统一
- 表情动作：自然、有感染力
- 环境氛围：光线、天气、时间
- 音频同步：对白、音效、配乐

**输出规格**：
- 分辨率：1080P
- 时长：30秒-3分钟
- 格式：MP4 (H.264)

### 3. 科幻类视频

**目标**：展示未来科技、创造视觉奇观

**Blender设置**：
- 场景：未来城市、太空、实验室
- 特效：粒子、光束、能量场
- 载具：飞船、机器人、装置
- 镜头：穿梭、俯冲、环绕

**AI增强重点**：
- 光效：霓虹、激光、能量
- 粒子：火花、尘埃、光点
- 材质：金属、玻璃、能量体
- 运动：流畅、有物理感

**输出规格**：
- 分辨率：1080P或4K
- 时长：10-30秒
- 格式：MP4 (H.264)

## 质量标准

### 视觉质量

## 常见问题解决

### 问题：渲染全黑

**原因**：摄像机没有对准物体
**解决**：使用Track To约束

### 问题：AI生成视频抖动

**原因**：首帧质量不够
**解决**：提高Blender渲染质量，添加更多细节

### 问题：角色变形

**原因**：缺少参考图
**解决**：提供多角度角色参考图

### 问题：场景跳变

**原因**：提示词不够具体
**解决**：添加更详细的环境和镜头描述

## 性能优化

### Blender渲染优化

- 使用EEVEE引擎（比Cycles快10倍）
- 降低采样率（64-128足够）
- 减少反射/折射次数
- 使用实例化替代复制

### AI生成优化

- 使用480P快速迭代
- 确认效果后再用高分辨率
- 批量生成时使用相同种子
- 缓存常用prompt模板
