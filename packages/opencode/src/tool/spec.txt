Generate a verifiable specification document from a natural language requirement.

This tool uses a multi-agent pipeline to produce a high-quality OpenSpec specification:
1. Requirements decomposition (req-agent)
2. Architecture analysis (arch-agent)
3. Acceptance criteria design (accept-agent)
4. Verification rehearsal (test-agent)
5. Spec document generation (merge-agent)
6. Quality review (review-agent)
7. Iterative fix loop (fix-agent)

The output is a structured markdown document with:
- Clear overview and goals
- Detailed requirements with verification methods
- Acceptance criteria for each requirement
- Quality score and review feedback

Use this tool when the user wants to create a formal specification for a feature or task.
